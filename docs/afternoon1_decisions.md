## 2. 問ごとの判断（未回答）

### H26-G1-2 ファイアウォールの障害対応
- **設問3(1) の理由付け**: 解答例は「SW4 と L3SW の入れ替え」だけで、理由は本文に無い。解説では
  「DMZ 側は VLAN の違う2つの仮想 FW とタグを使わないサーバのあいだを中継するので L3 が要る。内側はタグで運ぶだけなので L2 で足りる」と組み立てた。
- **配点**: 50字の記述を目安の上限寄りの9点にした。

### H26-G1-3 ネットワークのセキュリティ対策
- **配点**: 図を完成させる 3(2) を8点にした（目安は3点前後）。空欄3つと矢印2本を描くため。
  目安どおりにするなら、記述のどれかを6点に上げて50点に合わせる。
- **記述欄にした短い欄**: 4(1) b「ネットワークの切断」（答えが用語ではなく作業の内容なので `essay`）。

### H27-G1-1 シングルサインオンの導入
- **配点**: 11行しかなく、目安どおりだと50点に届かないので重めにした。
  穴埋め2点、設問2（図2 の番号）と設問3(1)（ドメイン名）各6点、25字・30字の記述各8点、40字の記述9点、ARP の名称3点。

### H27-G1-2 ファイアウォールの負荷分散
- **行の分け方と配点**: 設問2(1) は (A)・(B) ごとに「宛先 IP アドレス：…，宛先 MAC アドレス：…」の1行にまとめ、各4点。
- **配点**: 30字の記述は、設問3(3) を6点、設問2(3) と設問3(4) を7点。

### H27-G1-3 侵入検知・防御システムの導入
- **配点**: 穴埋め ア〜オ 各2点、表を完成させる 2(1) 6点、記述は 25字5点・35字6点・40字8点・50字9点。
- **2(1) の解答の形**: 表の1行を「通信の範囲：インターネット⇔内部 LAN，SW1：○，SW2：×，SW3：○」の1行にし、記述欄にしない。
- **記述欄にした短い欄**: 3(2)「通信をそのまま通過させ，遮断しない機能」（25字）。
- **図1・図2 のレイアウト**: 原図で F 社の枠の左の外にあるインターネット・モバイル端末・略語の説明を、
  375px に合わせて枠の上（インターネット・モバイル端末）と下（略語の説明）へ移した（図の注記に明記）。

### H28-G1-1 電子メールシステム
- **配点**: ア〜エ 各2点、2(1) 記述25字 8点、2(2)「ルータ 4」6点、オ・カ・キ 2・4・2点、2(4) 3点、
  2(5) ①② 各3点、3(1) 4点、3(2) 記述20字 7点。
- **2(5) の分け方**: 解答例が「① ・110 ② ・587」と「・」で並べてあるので順不同と読み、①・② の2行に分けた。
  どちらの欄に書いてもよいことを解説に書いた。
- **記述欄にした短い欄**: 3(2)「送信元メールサーバの IP アドレス」（20字）。
- **図1 の色分け**: ISP（P 社・Q 社）のルータとサービスネットワークは `outside`（灰）、
  A 社・B 社のルータと FW は `device`（青）、サーバは持ち主によらず `host`（橙）。
