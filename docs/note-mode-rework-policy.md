# ノートモード全面見直し方針（v1.0）

作成日: 2026-07-11
状態: 方針提案（ユーザーレビュー待ち）

---

## 1. 背景と課題認識

### 1.1 現状の成り立ち

ノートモードは「復習ノートPDF（85ページ・赤シート暗記用）」の忠実移植として構築された
（git履歴: 「16カテゴリを復習ノート準拠に刷新」等）。赤字の選定もPDFの赤字をそのまま踏襲している。

- 規模: 22カテゴリ / 130セクション / 赤字トークン約756個（NOTE_DB 約4,500行）
- データは `src/pages/NoteDetail.tsx` に直書き（ファイル全体で約5,400行）

### 1.2 学習フェーズの変化

ユーザーは午前Ⅱをある程度解ける段階に到達し、次は午後Ⅰ。
ノートモードの目的を「午前Ⅱ用語の暗記補助」から
**「午後Ⅰを解くために必要十分な知識を最短で確認・習得できる知識カード集」** に再定義する。

### 1.3 見直しで確認した問題点

#### (a) 赤字に基準がない（ユーザー指摘の核心）
- 一般語・断片語が赤字になっている:
  「静」「動」「簡単」「しない」「小さい」「先」「内」「安」「全て」「待ち」など
- 単語の途中で赤字が割れている: 「ブ」+「ロード」、「回線速」+「度」
- 句読点・記号入り赤字: 「フォワーディング。」「：SIP」「,」
- 逆に、隠して暗記テストとして成立しない赤字（隠すと文意が消えるだけの語）が多数

#### (b) 午後Ⅰ向けの知識が薄い
- 本文は「用語と事実」中心。午後Ⅰで問われる**「理由・仕組み・設計判断・定番記述」**が乏しい
- `exam_tips`（★試験で狙われるポイント）は質が高いが各カテゴリ5〜6行のみ

#### (c) 重複・構成のねじれ（PDFのページ順の名残）
- SSL/TLS が `security` と `ssl-tls` の両方に存在
- DoS・Webアプリ攻撃・標的型攻撃が `layer4-7` / `security` / `threat` に分散重複
- 「ネットワーク冗長化まとめ」が `load-balancer` 配下にある
- NAT/NAPT・QoS・TCP詳細（再送・MSS/MTU）が「補足（参考）」扱い
  → 午後Ⅰでは主戦場なのに参考扱いになっている

#### (d) 頻出分野と厚みが一致していない
アプリ内蔵の午後Ⅰ過去問38問（H25〜）のキーワード集計:

| 頻度 | 分野 |
|---|---|
| 7 | 認証・SSO / ルーティング |
| 6 | 冗長化 / セキュリティ |
| 5 | HTTP・CDN |
| 4 | VPN |
| 3 | 運用管理・監視 / WAN / クラウド / 無線LAN / ゼロトラスト・SWG |
| 2 | NAT・IPv6移行 / VoIP / SDN / DNS / QoS |

→ 最頻出の「認証・SSO」が現ノートでは security 内の2セクションのみ。
→ 「冗長化」は vrrp / load-balancer / layer1-3(STP) に分散。

## 2. 方針（決定事項）

### 方針1: 赤字基準の明文化と全面適用【最優先】

**赤字 = 「試験の解答欄に書く可能性がある語・数値」のみ。**

赤字にするもの:
- **R1 用語**: プロトコル名・技術名・機能名（GARP、DAI、SYN Cookie、OP25B、リンクローカルアドレス…）
- **R2 数値**: 試験頻出の数値（ポート番号、ビット幅、MTU/MSS値、規格番号 802.1X…）
- **R3 記述キーフレーズ**: そのまま午後の解答に使える連続句
  （例: 「送信元MACアドレスを学習」「GARPでMACアドレステーブルを更新させる」）

赤字にしないもの:
- **N1 一般語**: 動詞・形容詞・副詞単体（する/しない/小さい/簡単/静/動）→ plain。対比の強調は navy
- **N2 断片**: 単語の一部だけの赤字 → 語全体を1トークンにするか plain に戻す
- **N3 一般名詞単体**: サーバ/ポート/ルータ等（文脈上の専門用語になっている場合のみ可）
- **N4 記号・句読点を含む赤字**

運用基準:
- 箇条書き1行につき赤字は原則1〜2個、1セクション平均3〜6個
- 判定テスト: **「赤字を隠した状態で読んで、想起問題として成立するか」**
  成立しない（当てようがない／覚える価値がない）なら赤字にしない
- 想定規模: 756個 → 450個前後に削減（機械チェック + 全件レビュー）

### 方針2: 各カテゴリに「午後の定番」ブロックを追加

新しいセクション型 `examQA` を導入:

```
Q: VRRPの切替後、マスタルータがGARPを送信する目的を35字以内で述べよ。
A: L2SWのMACアドレステーブルを更新させ、仮想MAC宛てフレームを新マスタに届けるため。
キーワード: MACアドレステーブル / 更新
```

- 午後Ⅰの設問形式（「〜の理由を◯字以内で述べよ」）に合わせた問いと模範解答（25〜45字）
- 解答はタップで表示（赤字マスクと同系のUI）
- 各カテゴリ5〜10問。ソースは内蔵過去問のキーワード＋定番論点
- 既存 `exam_tips` は維持し、記述で問われる形のものは examQA へ昇格

### 方針3: カテゴリ構成の整理

| 対象 | 変更 |
|---|---|
| SSL/TLS | `security` から削除し `ssl-tls` に一本化 |
| `security` | 認証・SSO・SAML/Kerberos・802.1X+RADIUS に純化（最頻出分野を厚く） |
| 攻撃系 | `layer4-7` の DoS、`security` の標的型/Webアプリ攻撃 → `threat` に一本化 |
| 冗長化 | `vrrp` + `load-balancer` 内の冗長化まとめ + STP比較 → 「冗長化」として再編 |
| 補足の昇格 | NAT/NAPT・QoS・TCP詳細（再送/MSS/MTU）を「補足（参考）」から本編へ |
| `protocol-review` | ポート番号・レイヤ表の「直前確認」用に純化して維持 |
| 全体 | 誤字・断片赤字・全角/半角混在の総点検 |

### 方針4: 不足トピックの補強（最小限）

「最短で必要十分」を守るため、**午後Ⅰ出題実績があるものだけ**追加する:

- 認証・SSOの流れ（802.1X + RADIUS、SAML）— 頻出1位なのに薄い
- NAPT詳細（ポート枯渇・静的NAT・NAT越え）
- QoS（優先制御・シェーピング/ポリシング・DSCP）
- TCP詳細（再送・ウィンドウ・MSS/MTU調整とフラグメント）
- HTTP/3・QUIC、SWG/ZTNA（令和7年出題実績、requirements.md ギャップ表 G-01/G-02）

追加しないもの: 午前Ⅱ専用の細かい規格値・歴史的経緯・実務Tips。

### 方針5: データ構造とUI（作業を支える変更）

- `NOTE_DB` を `src/data/notes/<category>.ts` に分割（教科書の `chapters/` と同じ構成）
  → カテゴリ単位の段階改訂・レビューを可能にする
- 既存UIは維持: 赤字マスク / 理解度チェック（緑黄赤） / 見出し検索 / 前後ナビ
- 追加するUI（コンテンツ改訂後）:
  - examQA の解答マスク表示
  - 理解度「まだ難しい/なんとなく」のセクションだけ絞る復習フィルタ
  - ノート ⇔ 教科書該当章の相互リンク
- 新UIよりコンテンツ改訂を優先する

## 3. 進め方（フェーズ計画）

| フェーズ | 内容 |
|---|---|
| **Phase 0** | NOTE_DB のデータ分割 / 赤字リントスクリプト（1文字・断片・記号入り赤字の機械検出） |
| **Phase 1** | 午後Ⅰ頻出順にカテゴリ改訂（赤字見直し + examQA + 重複整理を同時に実施）<br>① security（認証・SSO純化）+ ssl-tls<br>② routing + 冗長化再編（vrrp/load-balancer/STP）<br>③ firewall（NAT昇格）+ proxy + dns<br>④ mail + ipsec + wan<br>⑤ layer1-3 + layer4-7（TCP詳細昇格）+ threat 一本化<br>⑥ wireless + voip（QoS昇格）+ dhcp<br>⑦ ipv6 + sdn + network-mgmt + iot + protocol-review純化 |
| **Phase 2** | 不足トピック補強（HTTP/3・SWG等） |
| **Phase 3** | UI追加（examQAマスク・復習フィルタ・教科書リンク） |

各バッチ完了ごとにユーザーレビューを挟む（教科書モードのグループレビューと同じ運用）。

## 4. 役割分担の整理（モード間）

| モード | 役割 |
|---|---|
| 教科書モード | ゼロから理解を作る（別トラックで全面作り直し中） |
| **ノートモード** | **理解済み知識の圧縮確認・暗記・午後Ⅰ定番論点の習得** |
| クイズ | 午前Ⅱ演習 |
| 午後問題 | 過去問実戦（PDF + 自己採点） |

ノートは「教科書を読み終えた人が試験前に回す場所」。理解の説明は教科書に任せ、
ノートには結論・数値・理由の要点・定番記述だけを置く。
